# dissertation-code
Hello! This repository contains all the code used for this dissertation. 

Unfortunately, I have not shared the corpus or dataset due to fears of running into copyright issues. 

If you would like to reconstruct the same data, the search query and time period filters are mentioned in the methodology section of the dissertation. News articles were downloaded from https://global.factiva.com and the LSE library offers free access to the site. 

Data Directory: 

Corpus creation and text cleaning: Pipeline.qmd
BERTopic training and optimization: FinalBERT.ipynb
SiEBERT training: sentiment.ipynb
Topic Modelling Statistical Analysis: TM_DID.qmd
Sentiment Analaysis Statistics: sentimentReg.qmd
